# ToDo App

A simple Python project created for educational purposes.

This application allows users to manage tasks through a graphical user interface. Task data is stored in an SQLite database.

## Features

* Add tasks
* View all tasks
* Delete tasks
* Mark tasks as completed
* Mark tasks as not completed

## Technologies

* Python
* Tkinter
* SQLite
* Object-Oriented Programming (OOP)

## How to Run

Run the application with:

`python main.py`

## Purpose

This project was created to practice Python, object-oriented programming, Tkinter, and SQLite while building a simple desktop application.
